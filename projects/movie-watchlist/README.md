# Personal Movie Watchlist Dashboard (Vanilla JS Final Project)

## Features Implemented
- Fake API fetch (simulated network + data)
- Form validation (title length, duplicates)
- Add movie
- Toggle watched / unwatched state
- Filters (all / watched / unwatched)
- Derived stats (count, avg rating)
- localStorage-style persistence (file in this case)
- Error states handled
- Fully runnable with node

Run:
```bash
node projects/movie-watchlist/index.js
```

This completes the JS curriculum requirements.
